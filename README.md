## Структура
- `RTSD_data.ipynb` — подготовка данных;
- `RTSD_training_and_app.ipynb` — обучение моделей, сравнение,
  стресс-тестирование и Gradio;
- `data/` — метаданные;
- `examples/` — примеры правильных и ошибочных классификаций;
- `models/` — обученные модели;
- `results/` — результаты экспериментов.
